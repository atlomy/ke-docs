Loading order (load-bearing)​

The skeleton renders KE stylesheets AFTER Unfold's unfold/css/styles.css so KE tokens override Unfold Tailwind utilities on equal specificity. Do NOT put KE stylesheets in UNFOLD['STYLES'] — that block renders BEFORE Unfold's own CSS, and you'll lose every cascade fight.

Theme path​

ke_theme cookie  →  ke_context  →  data-theme="light|dark|auto"  →  ke_tokens.css selectors
                                  AND
                                  early-paint script in skeleton  →  syncs Alpine `adminTheme` localStorage  →  removes/adds class="dark"

Alpine's $persist().as('adminTheme') writes to localStorage key adminTheme (NOT _x_adminTheme). Our early-paint script writes both, defensively.

Tenant accent path​

connection.schema_name  →  ke_tenant_slug  →  data-tenant="<tenant-slug>|public"  →  --tenant-accent-* tokens (per-tenant block in ke_tokens.css)

New tenants append a [data-tenant="<slug>"] block in ke_tokens.css declaring their accent palette.

Term-form change view (slot-driven editor)​

URL: /admin/epistemic/epistemicentity/<uuid>/change/. Renders via change_form_outer_before_template = "admin/ke/_term_form_overlay.html".

Two-column layout: slot rows (left) + meta rail (right with Lifecycle / Public preview / Slots panels). Variant C "Preview" toggle swings the meta rail out for a 50/50 split with <iframe src="/term/<uuid>/preview/?embed=1">.

Editing pattern (the JSONB-mirror): each slot row carries data-source="data.X". JS in _term_form_overlay.html listens to input events on .ke-slot-row__input, parses the source path, and writes the new value into the hidden Django JSONField <textarea name="data">. Standard ModelForm.save() persists. Reload re-evaluates composition templates server-side.

Path resolution: _build_slot_rows calls resolve_source_field(entity, source) (NOT entity.data). For data.Lemma Word this walks getattr(entity, "data")["Lemma Word"]. For lemma_full (no prefix) it walks getattr(entity, "lemma_full").

Row-detail drawer​

URL trigger: [data-ke-drawer-id="<uuid>"] button in the changelist. JS at atlomyapp/atlomy_static/assets/js/ke_drawer.js fetches /admin/epistemic/epistemicentity/<uuid>/drawer/ (returns HTML fragment), populates a position: fixed right slide-out container, ESC + scrim to close.

Public Term reader​

URL: /term/<uuid:id>/preview/ (route in atlomyapp/urls.py, view term_preview in atlomyapp/views_explorer.py). Server-rendered Django template; tenant identity from request Host via TenantMainMiddleware; ?embed=1 strips chrome for iframe use. Reuses _build_slot_rows projection.

Display tweaks (floating widget)​

A <details class="ke-tweaks ke-tweaks--floating"> rendered at the END of <body> in skeleton.html so it appears on every admin page (login + dashboard + change list + change form) regardless of which template chain is rendered. Top-right placement; tucked above the + Add button. Posts to /admin/ke/prefs/ (handler atlomyapp.views_preferences.set_preferences); cookie-backed; reload picks up the new attrs from ke_context.

How to use the research workspace UI​

For a researcher curating tenant data:

Browse + drill in​

  1. Sidebar → KE Workbench → Terms (or any archetype). Live counts show how much data exists per archetype.
  2. Changelist surfaces the Preview column = first slot config by display_order resolution. For TERMs this is lemma_full (composed Greek headword). If a row shows —, the slot config's source_field doesn't match the actual data keys — that's a tenant config drift, not a UI bug.
  3. Click a row's "Quick" pill → right slide-out drawer opens with all slot data.
  4. Click the row's link → full term-form change view: editable slot rows on the left, meta rail on the right.

Edit + save​

  1. Type in any slot input. JS mirrors the value into the hidden JSONB blob in real time.
  2. Click Save (or Save and continue editing). Standard ModelForm persists; reload re-evaluates composition templates.
  3. The Lifecycle block (right rail) shows Modified N minutes ago to confirm.

Public preview​

  • Right rail → "Public preview" → "Open in new tab" → standalone scholarly-styled reader at /term/<uuid>/preview/.
  • OR top-of-form Preview button → embedded iframe of ?embed=1 variant alongside the editor (Variant C split view).

Display tweaks​

  • Floating top-right tune icon → dropdown for theme (auto/light/dark), density (compact/cozy/comfortable), typeface (sans/serif/brand). Apply → cookies set → page reloads with new tokens.

When to extend the design vocabulary​

If you need a new visual atom:

  1. Try existing tokens first: --canvas, --panel, --ink-1/2/3, --tenant-accent, --cap-*, --ai-*. Most cases compose from these.
  2. Add a .ke-* selector in ke_components.css (NOT inline styles in templates). Prefix all selectors with .ke- to avoid colliding with Unfold/Tailwind.
  3. For a per-tenant accent, add [data-tenant="<slug>"] { --tenant-accent: ...; } blocks in ke_tokens.css (one for each data-theme combination if needed).
  4. For density variants, key the new property with [data-density="compact|cozy|comfortable"].

Spacing System​

We adhere to a 4px grid system.

  • p-1 (4px): Tight grouping
  • p-2 (8px): Button padding
  • p-4 (16px): Standard container padding
  • p-6 (24px): Section separation

Visual Effects​

Mica Material​

For glass-like effects (modals, floating panels), use the mica-surface class:

.mica-surface {
  background: linear-gradient(135deg, rgba(255,255,255,0.05), rgba(255,255,255,0.02));
  backdrop-filter: blur(20px);
}

Shadows​

Use standard Tailwind shadows (shadow, shadow-md, shadow-xl) to define elevation. Higher elevation implies higher Z-index.

Component Standards​

Buttons​

  • Primary: Solid background, white text.
  • Secondary: Outline border, primary text.
  • Ghost: Transparent background, primary text (for icons).

Cards​

  • Rounded corners (rounded-lg or rounded-xl).
  • Subtle border in dark mode for contrast.
  • Hover effects (hover:shadow-md) for interactive cards.

Theming & Customization (New Sprint 15)​

We support dynamic multi-theming via CSS variables and the ThemeContext.

Supported Themes​

  1. Default (Atlomy):
    • Primary: Blue (#0078d4)
    • Font: Sans-serif (System)
  2. Research Pilot Theme:
    • Primary: Emerald Green (#10b981)
    • Secondary: Gold (#d97706)
    • Font: Serif (Amiri/Georgia)
    • Activation: document.body.dataset.theme = 'research-pilot'

Usage within React​

const { theme, setTheme } = useTheme();
// toggle
setTheme('research-pilot');

Internationalization (RTL)​

We support full RTL layout mirroring for Arabic language support via LanguageContext.

Logical Properties​

Always use Logical Properties instead of physical direction for margins, padding, and positioning to ensure automatic mirroring:

  • Bad: margin-left, padding-right, left: 0
  • Good: margin-inline-start (ms-*), padding-inline-end (pe-*), inset-inline-start (start-*)

Global Direction​

The dir attribute is managed globally on the root element:

<html dir="rtl" lang="ar">

Component-level overrides (e.g., for specific English quotes in an Arabic text) should use dir="ltr" explicitly.

Wizard token import strategy​

Sprint A.1.1 delivers a Django management command manage.py generate_wizard_tokens that filters docs/design/system/tokens.css into a generated atlomyapp/atlomy_static/assets/css/ke_wizard_tokens.css with a "do not edit by hand" header. The design-system file remains source-of-truth; the production asset is intentional + reviewable. See spec 0017 design.md §6 for the A/B/C trade-off (Option C chosen). Tokens in scope: typography (--font-brand/sans/serif/greek/arabic/mono, --t-*), color (--ink-*, --surface-*, --rule-*, --paper, --card, --inset, --ok*, --warn*, --err*, --tenant-accent*), spacing (4/8/12/16/20/24/32/40/56/80), radius (3/6/8/12), card/drawer/sticky-title shadows, motion timings.

Comfort dial (Sprint B)​

Stage 3 hosts a 4-level slider ("Hands off / Stay informed / Ask if unsure / Confirm everything") controlling how aggressively the wizard auto-applies AI proposals. Sprint B delivers; ADR-033 must land first — it resolves the level → risk_class × confidence × proposal_kind matrix, per-tenant default level, recompute-at-apply interaction, and audit-trail semantics. Persistence: MappingProject.comfort_level (IntegerField 0–3, default 1). See spec 0017 design.md §7.1 for the strawman matrix and the open questions ADR-033 owns.

Stacked undo bar (Sprint C)​

Fixed-bottom toast surfacing system-applied changes with an 8s reversal window. Sprint C delivers; ADR-034 must land first — it resolves the reversal semantics (transactional staging vs compensating-action saga vs mixed) and the ImportTemplate entity shape. The wires-v4 single-slot UndoContext is replaced with a stacked queue (up to 3 concurrent toasts; oldest drops first if a 4th arrives). See spec 0017 design.md §7.2 for the option matrix.
