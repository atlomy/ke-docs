SPA Development (Frontend)​

To enable real-time updates for the React SPA inside the Docker container:

  1. Start watcher — in a separate terminal: 
    docker exec -it django_app npm run watch --prefix spa
  2. Edit — .tsx / .scss files under spa/src/.
  3. Verify — refresh the browser; assets are compiled to /static/spa/.

For the React 19 patterns and the legacy-to-19 upgrade path, see the project skills at skills/react-patterns/ and skills/react-19-upgrade/.
