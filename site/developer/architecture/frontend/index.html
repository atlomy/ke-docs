Architecture: Frontend Strategy (React 19 + Django)

Overview​

Atlomy Atlas uses a Hybrid Operational/Epistemic Architecture (ADR-001).

  • Operational Layer (Canonical): Managed via Django Admin using django-unfold.
  • Epistemic Layer (Knowledge): Managed via embedded React 19 Applications.

Tech Stack​

  • Framework: React 19
  • Language: TypeScript 5
  • Build: Webpack 5 (Multi-entry configuration)
  • Styling: Tailwind CSS + Radix UI Primitives
  • Data Fetching: TanStack Query + GraphQL (via graphql-request)

Embedded Application Pattern​

React apps are treated as "Islands of Interactivity" embedded specifically within Django Admin templates. We do NOT run a separate frontend server. Django serves the compiled JS bundles.

Directory Structure (spa/)​

  • src/index.js: Legacy SPA entry (currently disabled for migration).
  • src/apps/: Container for distinct React micro-apps.
    • src/apps/schema_review/: The Schema Review Interface (Sprint 11).
    • src/apps/database_visualizer/: Epistemic Schema Graph (Sprint 12).
    • src/apps/knowledge_explorer/: Faceted Search & Data Explorer (Sprint 13).

Integration Mechanism​

  1. Template: A Django Admin template (e.g., change_form.html) defines a mounting div.
  2. Date Attributes: Context (IDs, CSRF tokens) is passed via data-* attributes on the mount node.
  3. Bundle: The Webpack bundle (static/spa/js/[name].bundle.js) is loaded via {% static %}.
  4. Mounting: The React entry point (index.tsx) reads the data attributes and hydrates the root.

Development Workflow​

  1. Navigate to spa/ directory.
  2. Run npm run start (dev server with write-to-disk enabled).
  3. Django picks up the changes on refresh.
  4. For production, npm run build outputs optimized bundles to static/spa/.

React 19 Upgrade Notes​

  • Actions: Use React 19 Actions for form submissions (e.g., Approve/Reject workflows).
  • Build: Requires --openssl-legacy-provider on newer Node versions if crypto errors occur.
  • Legacy Compat: The legacy main entry point is disabled until it can be refactored for React 19 compatibility.
