Role-Based Access Control (RBAC) Architecture

Overview​

Atlomy Atlas uses a Tenant-Isolated Permission System built on top of the standard django.contrib.auth. While Users and Groups are technically stored in the public schema (shared via SHARED_APPS), their administrative context and permission associations are managed strictly within the tenant's scope.

Standard Roles​

We enforce 4 standard roles across all tenants. These are provisioned via the provision_roles management command.

RoleAccess LevelResponsibilities
ViewerRead-OnlyViewing content, browsing public pages.
EditorRead/WriteCreating Lemmas, Events, Pages, and managing Bibliography.
EngineerPower UserManaging Data Imports (Wizard), retired external no-code surface Sync, and Database Visualizations.
AdminFull ControlManaging Users, Groups, System Settings, and Platform Monitoring.

Implementation Details​

1. Provisioning Script​

The authoritative source for role definitions is atlomyapp/management/commands/provision_roles.py. Usage:

python3 manage.py tenant_command provision_roles --schema=<tenant_name>

2. Dashboard Filtering​

The React Dashboard (atlomyapp/dashboard.py) implements permission-aware filtering. Navigation items are hidden if the user lacks the required view permission for the target model.

  • Editor Workspace: Shows Content tools + User Management (for Admins).
  • Engineer Workspace: Shows Data tools.
  • Admin Workspace: Shows System tools.

3. Middleware & Isolation​

  • Authentication: Handled by django.contrib.auth.
  • Isolation: django-tenants ensures that when a user logs in to tenant1.atlomy.org, their session and permission checks occur within that schema's context.
  • User Management: The TenantMembership model (in customers) links Users to Tenants, defining their specific role for that project.

Adding New Roles​

Do not manually create Groups in the Admin UI for standard roles. Instead:

  1. Update atlomyapp/management/commands/provision_roles.py.
  2. Run the provisioning command across all tenants to ensure consistency.
