Key Components​

Sprint 9​

ArchetypeDetector (retired external no-code surface/services/archetypes.py)​

Purpose: Detect table archetype with confidence scoring

Usage:

from retired external no-code surface.services.archetypes import ArchetypeDetector

detector = ArchetypeDetector()
result = detector.detect(table_schema)

print(result.archetype)           # 'blog_post'
print(result.confidence)          # 0.95
print(result.is_high_confidence)  # True
print(result.reasoning)           # ["Has 'title' field", ...]

Confidence Calculation:

confidence = (
    required_field_matches * 0.5 +
    optional_field_matches * 0.3 +
    type_accuracy * 0.2
)

Adding New Archetypes:

# In ARCHETYPES dict:
'my_archetype': {
    'name': 'My Archetype',
    'required_fields': ['id', 'name'],
    'optional_fields': ['description', 'created_at'],
    'field_patterns': {
        'name': ['SingleLineText'],
        'description': ['LongText']
    }
}

RelationshipDetector (retired external no-code surface/services/relationship_detector.py)​

Purpose: Detect relationships from LinkToAnotherRecord fields

Usage:

from retired external no-code surface.services.relationship_detector import RelationshipDetector

detector = RelationshipDetector()
relationships = detector.detect_relationships(table_schema, all_tables)

for rel in relationships:
    print(rel.field_name)          # 'author'
    print(rel.relationship_type)   # 'one_to_many'
    print(rel.target_table)        # 'Authors'
    print(rel.django_code)         # 'models.ForeignKey(...)'

Supported Relationship Types:

  • one_to_many (bt, hm)
  • many_to_many (mm)
  • self_referential (parent/child)

SchemaAdapterService (retired external no-code surface/services/schema_adapter.py)​

Purpose: Orchestrate schema adaptation

Key Methods:

from retired external no-code surface.services.schema_adapter import SchemaAdapterService

adapter = SchemaAdapterService()

# Enhanced archetype detection
result = adapter.detect_archetype_enhanced(table_schema)

# Relationship detection
relationships = adapter.detect_relationships(table_schema, all_tables)

# Generate complete suggestion
suggestion = adapter.generate_schema_suggestion(
    workspace,
    table_schema,
    all_tables
)
suggestion.save()

# AI column mapping
mappings = adapter.suggest_column_mappings_ai(
    csv_headers=['Post Title', 'Author Name'],
    retired external no-code surface_fields=['title', 'author'],
    table_context='Blog Posts'
)
# Returns: {'Post Title': {'retired external no-code surface_field': 'title', 'confidence': 0.95}}

Validation System (data_import/validators.py)​

Architecture: Composite pattern

from data_import.validators import (
    DataTypeValidator,
    EncodingValidator,
    DuplicateValidator,
    RequiredFieldValidator,
    CompositeValidator
)

# Individual validators
type_validator = DataTypeValidator(schema)
encoding_validator = EncodingValidator()
duplicate_validator = DuplicateValidator('email')
required_validator = RequiredFieldValidator(['name', 'email'])

# Composite validator
composite = CompositeValidator([
    type_validator,
    encoding_validator,
    duplicate_validator,
    required_validator
])

# Run validation
result = composite.validate(data)

if not result.valid:
    for error in result.errors:
        print(f"Row {error.row}, Field {error.field}: {error.message}")

ValidationResult Structure:

@dataclass
class ValidationResult:
    valid: bool
    errors: List[ValidationError]
    warnings: List[ValidationError]
    
    def add_error(self, row, field, message, value): pass
    def add_warning(self, row, field, message, value): pass

Adding Custom Validators:

class MyCustomValidator:
    def validate(self, data: List[Dict]) -> ValidationResult:
        result = ValidationResult(valid=True, errors=[], warnings=[])
        
        for row_idx, row in enumerate(data, start=1):
            # Your validation logic
            if not my_check(row):
                result.add_error(row_idx, 'field', 'Error message', row['field'])
        
        return result

# Use it
my_validator = MyCustomValidator()
validators.append(my_validator)

SchemaSuggestion Model​

class SchemaSuggestion(models.Model):
    workspace = ForeignKey(retired external no-code surfaceWorkspace)
    table_mapping = ForeignKey(retired external no-code surfaceTableMapping, null=True)
    
    # Archetype
    archetype = CharField(max_length=50)
    archetype_confidence = FloatField()
    secondary_archetype = CharField(max_length=50, blank=True)
    secondary_confidence = FloatField(default=0.0)
    archetype_reasoning = JSONField(default=list)
    
    # Field Suggestions
    field_suggestions = JSONField(default=dict)
    # Example: {
    #   "title": {
    #     "django_type": "CharField",
    #     "options": {"max_length": 255},
    #     "confidence": 0.95,
    #     "reasoning": "Mapped from SingleLineText"
    #   }
    # }
    
    # Relationships
    relationship_suggestions = JSONField(default=list)
    # Example: [{
    #   "field_name": "author",
    #   "relationship_type": "one_to_many",
    #   "target_table": "Authors",
    #   "django_code": "models.ForeignKey(...)",
    #   "confidence": 1.0
    # }]
    
    # Review
    status = CharField(choices=STATUS_CHOICES, default='pending')
    reviewed_by = CharField(blank=True)
    reviewed_at = DateTimeField(null=True)
    review_notes = TextField(blank=True)

Top-level confidence naming is intentionally specific:

  • archetype_confidence is the confidence for the table-level archetype classification.
  • Nested confidence keys inside field_suggestions and relationship_suggestions are per-suggestion scores, not aliases for archetype_confidence.
  • Multilingual processing has its own unrelated language-detection confidence value in data_import/services/multilingual.py.

Archetype Detection Test:

def test_blog_post_detection():
    schema = {
        'id': 'table_1',
        'columns': [
            {'title': 'title', 'uidt': 'SingleLineText'},
            {'title': 'content', 'uidt': 'LongText'},
            {'title': 'author', 'uidt': 'SingleLineText'},
            {'title': 'published_date', 'uidt': 'Date'},
        ]
    }
    
    detector = ArchetypeDetector()
    result = detector.detect(schema)
    
    assert result.archetype == 'blog_post'
    assert result.confidence >= 0.9

Validation Test:

def test_email_validation():
    schema = {'email': {'type': 'Email'}}
    data = [{'email': 'invalid'}]
    
    validator = DataTypeValidator(schema)
    result = validator.validate(data)
    
    assert not result.valid
    assert len(result.errors) == 1
    assert result.errors[0].field == 'email'

Performance Considerations​

Sprint 9​

Archetype Detection:

  • ✅ Fast: O(n) where n = number of fields
  • ✅ No external API calls (rule-based)
  • Expected: <1s for typical tables (<100 fields)

Optimization Tips:

  • Cache ArchetypeDetector instance
  • Batch-process multiple tables
  • Only re-detect when schema changes

Sprint 10​

Validation:

  • ✅ Streaming: validates row-by-row
  • ⚠️ Memory: loads entire CSV (use chunking for >100k rows)
  • Expected: ~1000 rows/second

Optimization Tips:

# For large files, validate in chunks
CHUNK_SIZE = 10000
for chunk in pd.read_csv(file, chunksize=CHUNK_SIZE):
    result = validator.validate(chunk.to_dict('records'))

Troubleshooting​

Sprint 9​

"Confidence too low":

  • Check archetype_reasoning for why
  • Add missing fields to archetype definition
  • Consider secondary archetype

"Relationship not detected":

  • Verify LinkToAnotherRecord field exists
  • Check colOptions.type is set
  • Ensure target table in all_tables

Sprint 10​

"Mojibake detected" false positive:

  • Check if text actually contains Ã pattern
  • May be legitimate content (rare)
  • Override validator if needed

"Validation too slow":

  • Use chunked reading for large CSVs
  • Disable unnecessary validators
  • Consider async validation

ImportPreviewView (POST):

  • Phase 2: REST API Endpoints (Completed)
  • URL: /data-import/api/import/preview/
  • Body: Multipart form (file, workspace_id, table_id)
  • Returns: JSON preview with row-level validation status

ImportExecuteView (POST):

  • URL: /data-import/api/import/execute/
  • Body: Multipart (file, table_mapping_id, column_mapping, skip_duplicates)
  • Returns: Job ID and status 'queued'

ImportStatusView (GET):

  • URL: /data-import/api/import/status/{job_id}/
  • Returns: Job status, progress %, row counts, validation_errors (list), skipped_row_details (list)

ImportCancelView (POST):

  • URL: /data-import/api/import/cancel/{job_id}/
  • Returns: Status 'cancelled'
