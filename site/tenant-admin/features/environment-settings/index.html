Environment-Level Settings

Purpose​

A small set of defaults live on your environment as a whole, rather than on any one import, field, or record. Each one shapes how a recurring activity starts out: how involved you are by default when new data arrives, how much AI assistance a single import-wizard session may use, and whether your environment's not-yet-reviewed vocabulary takes part in cross-environment summaries. Read this when you want to understand what these environment-wide defaults do, what their limits are, and who can change them today.

These three settings are not edited from your own admin interface. They sit on the environment record that the platform operator manages, so changing any of them is an operator-mediated action — you decide what you want and ask your platform operator to apply it. The sections below mark each setting accordingly, so you know what to request and what to expect once it changes.

Features​

  • Default import autonomy — your environment carries a default answer to the import wizard's "How involved do you want to be?" question, used to pre-select the starting autonomy level for every new import. The four levels are Hands off, Stay informed, Ask if unsure, and Confirm everything; the environment default is Stay informed unless your operator sets it otherwise. The default only chooses the starting point — you can still change the level on any individual import, and your per-import choice always wins. Maturity: Active. Limit: this default is applied by your platform operator; there is no self-serve control for it in your admin interface today.

  • AI chat session budget — the import wizard's assistant chat runs against a per-session token budget drawn from this environment-wide figure. The default is 50,000 tokens per session, and the platform allows a value up to 500,000. A value of zero means no cap — the chat is unbudgeted. When a session reaches the budget, the chat pauses for that session; every import control keeps working, so the pause never blocks the import itself. Maturity: Active. Limit: this budget governs the import-wizard assistant chat only; it is separate from the rolling budget that governs AI vocabulary-grounding suggestions, which is configured elsewhere. The figure is applied by your platform operator.

  • Federation exposure for ungrounded vocabulary — by default, vocabulary values your environment has not yet reviewed can be included in future cross-environment summaries. Turning this off keeps your environment's not-yet-grounded values out of those summaries while your grounding work is still in progress, so only vocabulary you have reviewed represents your environment outside it. Maturity: Active. Limit: the control is on by default, applies to ungrounded values specifically, and is set by your platform operator.

Usability — how you use it​

None of these three settings is edited from the environment admin interface you work in day to day. To change one, decide the value you want and ask your platform operator to apply it on the environment record.

  • Default import autonomy — if your team consistently overrides the per-import autonomy setting to the same level, that is the signal to change the environment default. Tell your operator which of the four levels you want as the starting point. The change affects only imports started afterward; imports already in progress keep the level they were given. For what each level does inside a single import, see Data Import Wizard.

  • AI chat session budget — raise the figure if researchers report the wizard chat pausing before they are done in a session; lower it (or set zero for no cap) to suit your platform's posture. Because the budget is per session, a researcher who hits it can continue working immediately — only the chat pauses — and a fresh session starts again from the full budget. Confirm the new value with your operator.

  • Federation exposure for ungrounded vocabulary — turn this off while your environment still has a meaningful queue of unreviewed vocabulary and you would rather that queue not represent you in cross-environment summaries. As your grounding work catches up, you can ask your operator to turn it back on. For the review work this setting interacts with, see Vocabulary Grounding.
