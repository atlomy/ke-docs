Super Admin Documentation

Audience: Super admin / platform operator Last aligned with platform state: 2026-05-25 Platform version: V2 (pre-1.0)

Purpose​

This index is the entry point for the platform operator — the role that runs the platform, not any individual tenant. Read this when you are paged, when onboarding to the platform operator rotation, or when you need to find which doc owns which operational surface. The surfaces below all live under /admin/monitoring/platform/ (gated by require_platform_staff(...)) or via management commands. Tenant-local detail stays inside the tenant boundary; cross-tenant views are K-anonymized rollups only.

Features (index of operator surfaces)​

  • Platform monitoring — read-only operations surface, Import Wizard health, capture posture, telemetry rollups, canonical red-lines block. See platform_monitoring.md.
  • Incident operations — ack contract for capture-failure incidents, density preference, PaPostureModal interaction polish, CaptureFailureIncidentCard. See incident-operations.md.
  • Recommender metrics — K-thresholded cross-tenant recommender dashboards (Spec 0018 US-C.6): stratum-wide rejection-rate, low-prior shape-count lists, escalation timeline. Payload-level schema-name obfuscation for rare-archetype edge cases. See recommender-metrics.md.
  • Tip auto-pause — rolling 30-day tip-family acceptance ratio, K-anonymized weekly rollup, auto-pause policy, TIP_ROLLUP_MIN_K setting, K-anonymity floor clamp. See tip-auto-pause.md.
  • DPIA operations — DPIA refresh trigger audit rows for DecisionEvent capture enablement; Operations tab. See dpia-operations.md.
  • Federation and marketplace — unified federation/marketplace pattern across Ingest / Alignment / Workspace slots; how platform staff curate the Tier-1 anchor bundle catalog (ADR-043). See federation-and-marketplace.md.
  • Secrets management — ExternalServiceCredential substrate, AWS Secrets Manager references, validation and rotation runbook. See secrets-management.md.
  • LLM providers guide — provider routing for the In-Product AI Runtime single-call assist contract (ADR-014-α), Bedrock as the live provider, mock as the default in development. See llm_providers_guide.md.

Tenant lifecycle​

Tenant provisioning, billing, contract administration, and onboarding intake — refer to internal program documentation. Per-tenant data inspection requires entering the tenant boundary; the super-admin surfaces in this index never display tenant payload.

Troubleshooting — symptom-to-doc routing​

  • Capture-failure incident card, integrity warning class → incident-operations.md Troubleshooting + escalate to security on-call.
  • Stratum-wide rejection-rate spike, no escalation row → recommender-metrics.md Troubleshooting.
  • Tip family auto-paused unexpectedly → tip-auto-pause.md Troubleshooting.
  • DPIA refresh trigger missing acting admin → dpia-operations.md Troubleshooting.
  • ExternalCredentialUnavailable raised at request time → secrets-management.md Troubleshooting.
  • UnratifiedSearchEngineError returned to a GraphQL caller → platform_monitoring.md Troubleshooting + check the search profile registry.
  • AI assist call returns provider_unavailable → llm_providers_guide.md Troubleshooting.
  • Stale Import Wizard rollup lane → platform_monitoring.md Troubleshooting.
