Researcher Guide

Audience: Researcher Last aligned with platform state: 2026-05-25 Platform version: V2 (pre-1.0)

Purpose​

You are a scholar, student, archivist, or editor using a knowledge environment built on this platform. You sign in, read, search, edit drafts, and cite records. You do not run the system; you use it. This guide is the entry point for everything researcher-facing. Read it when you join a new environment, when a specific control is not behaving as you expect, or when you want to know what the platform is willing and unwilling to do for you.

If you configure the environment — turning columns on or off, adjusting which fields are searchable, managing other researchers' permissions — see the tenant admin guide instead. If you operate the platform across multiple environments, see the super admin guide.

Features​

The researcher surface delivers eight distinct capabilities, ordered by how often you will reach for them.

  • Workspace table view — the main table-of-records per record type, with toolbar, column manager, filters, density toggle, and Details panel. Substrate: Spec 0003 (docs/superpowers/specs/0003-tenant-workspace-navigation-manifest/), Spec 0028 (docs/superpowers/specs/0028-workspace-ui-parity-alignment/), ADR-036 (docs/developer/architecture/adr/036-workspace-operations-surface-split.md), spa/src/apps/tenant_admin/workspace/. Maturity: Active. Limit: visible controls per record type are tenant-configured; if a control is missing the administrator can expose it.
  • Inline editing and the draft lifecycle — Tab-into-field editing with autosave on blur, and a New row drawer with local mode → autosave-on-required-field → activate-or-discard. Substrate: Spec 0025 (docs/superpowers/specs/0025-workspace-ui-backend-contracts/), Spec 0027 (docs/superpowers/specs/0027-workspace-draft-relation-dependencies/), PR #411. Maturity: Active. Limit: relation fields on drafts are gated until activation (or until the draft-relation capability ships per Spec 0027).
  • Cross-script search — the toolbar Quick search runs over native script, transliteration, and translation for fields the project marked searchable. Substrate: ADR-011 (docs/developer/architecture/adr/011-search-engine-opensearch.md). Maturity: Active. Limit: only fields explicitly marked searchable in the tenant configuration are covered.
  • Media and citations — figures, audio, video, 3D models with a carousel that flips between variants for the same anchored point; every media item carries a CSL-format citation. Substrate: Spec 0008 (docs/superpowers/specs/0008-citation-framework-csl/), Spec 0016 (docs/superpowers/specs/0016-multi-media-expansion/), PRs #330–#334. Maturity: Active. Limit: which variant types exist for a record depends on what your project attached.
  • Public reader and draft preview — a stable read-only projection of activated and approved rows, with an in-workspace draft preview that renders exactly what a reader would see. Substrate: ADR-029 (docs/developer/architecture/adr/029-projection-first-published-entry-layer.md), Spec 0021, Spec 0022. Maturity: Active. Limit: which rows reach the reader depends on the project's activate/approve workflow.
  • Inline tips and guidance — small, dismissible suggestions in the workspace and in multi-step wizards (efficiency, standardization, improvement). Substrate: Spec 0030 (docs/superpowers/specs/0030-tip-recommendation-engine/), ADR-044, recommendations/services/tip_*.py, spa/src/apps/tenant_admin/components/TipsPanel.tsx. Maturity: Active. Limit: tips never edit data without explicit confirmation; tip families can be paused by administrators.
  • Accessibility surface — keyboard navigation, visible focus rings, density toggle, font scale, line height, font family, and color presets. Substrate: spa/src/components/AccessibilityControlPanel/, recent workspace a11y fixes (commit cda2f4cd). Maturity: Active. Limit: additional ARIA labeling and screen-reader announcement coverage is ongoing.
  • Privacy posture — payload-free aggregates, per-tenant HMAC redaction of sensitive strings, tamper-evident audit chain, K-anonymity floor on cross-tenant statistics, and the four-tier ambient chat retention regime. Substrate: ADR-016 (docs/developer/architecture/adr/016-telemetry-substrate.md), ADR-045 (docs/developer/architecture/adr/045-chat-transcript-retention-regime.md), telemetry/services/_redact.py. Maturity: Active. Limit: retention tiers above session-only require a Data Protection Impact Assessment.

Usability — how you use it​

Start with whichever matches what you want to do.

  • New to the workspace, or unsure where a control lives → Workspace walkthrough.
  • Creating a new record, picking up an abandoned draft, or editing an existing record → Adding and editing rows.
  • Hunting for a record across scripts, opening media, or reading citations → Searching and reading.
  • Curious about the small suggestions appearing beside the form or the table → Tips and guidance.
  • Driving the platform from the keyboard, or adjusting display settings → Accessibility.
  • Wondering what the platform records about you and what it does not → Privacy and safety.
  • Wanting to know what a reader outside the project sees, and how to preview it → Public reader.

A few conventions across all walkthroughs:

  • Bold marks an on-screen control name — for example, + New row, Add filter, Activate.
  • A code-style font marks a path, URL fragment, or literal value.
  • Examples use abstract content ("historical figures", "manuscript editions") rather than your specific project's records. The mechanics are the same regardless.

Troubleshooting​

SymptomLikely causeFixWhere to escalate
A column you expected is missing from the table.Either hidden in the current view, or not exposed by the tenant configuration.Open the column manager in the toolbar; if not listed, ask your tenant administrator to expose it.Tenant admin, then tenant admin Workspace docs.
A field is read-only when you expected to edit it.Permissions on your account, or a workflow rule for that record type.Confirm your role with your administrator; if intended, request elevated permissions for that record type.Tenant admin.
A draft will not activate.Missing a required field, or waiting on a workflow review step.The New row drawer surfaces the blocker inline — fill the field or wait for the review.If the blocker text is unclear, file with tenant admin; see Adding and editing rows.
Quick search returns nothing for a record you know exists.The relevant field is not marked searchable in the tenant configuration.Open the row directly via its Details panel; ask administrator to mark the field searchable.Tenant admin, then ADR-011.
You see a "not enough data" placeholder where a number was expected.A K-anonymity floor (a privacy floor that requires at least N records before a statistic is published) is clamping a cross-tenant statistic.This is intentional and not a fault. The number will appear once the underlying sample grows.Privacy and safety.
