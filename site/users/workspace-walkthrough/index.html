Workspace Walkthrough

Audience: Researcher Last aligned with platform state: 2026-06-10 Platform version: V2 (pre-1.0)

Purpose​

The workspace is the table of records of one type — figures, terms, manuscript editions, anything your project tracks — wrapped in a toolbar, a left sidebar, and a Details panel that slides in from the right. This page walks through what is on the screen, what each control does, and what a typical session looks like. Read it when you first open the workspace, when a control is doing something you did not expect, or when you want to set up a saved view you can come back to.

Features​

  • Workspace shell (toolbar, sidebar, table, Details panel) — the four-region layout common to every record type. Substrate: Spec 0003 (docs/superpowers/specs/0003-tenant-workspace-navigation-manifest/), Spec 0028 (docs/superpowers/specs/0028-workspace-ui-parity-alignment/), spa/src/apps/tenant_admin/workspace/Header.tsx, spa/src/apps/tenant_admin/workspace/ChromeBar.tsx. Maturity: Active. Limit: visible toolbar controls are tenant-configurable per record type.
  • Workspace search — a top-chrome search panel for finding records across the workspace, grouped by table, with result clicks opening the matching row route. Substrate: Spec 0037 (docs/superpowers/specs/0037-workspace-research-search-interface/), workspaceSearch GraphQL, WorkspaceResearchSearchPanel.tsx. Maturity: Active. Limit: live results respect your workspace permissions and depend on the tenant search index; on a tenant whose search engine has not been production-ratified yet, the panel says "Search isn't enabled for this workspace yet."
  • Rows named by your display column — record labels across the table, the Details and Relations panes, and linked-record pickers use the display column your source declared (for example a lexicon's full-form column), falling back to sensible label fields and never to opaque internal ids. Substrate: per-collection display_field (import detection → GraphQL → displayLabels.ts), PR #554. Maturity: Active. Limit: a collection with no declared or recognizable display column falls back to the platform default label.
  • Sidebar organizer and command palette — the left sidebar supports saved table groups, favorites, recent tables, collapse/expand, and reset; the command palette exposes those actions without leaving the workspace. Substrate: Spec 0028, Sidebar Reorg handoff, ArchetypeRail.tsx, CommandPalette.tsx. Maturity: Active. Limit: recently viewed rows are not yet tracked separately from recent tables.
  • Current-table quick filter — the toolbar free-text box that filters rows already loaded in the active table. Substrate: AG Grid quick filter through ArchetypeGrid. Maturity: Active. Limit: this is not a whole-workspace corpus search.
  • Filter chips — composable filter conditions (range, equality, membership) per facet exposed by the tenant. Substrate: spa/src/apps/tenant_admin/workspace/ (filter components). Maturity: Active. Limit: facets must be declared in the tenant's workspace navigation manifest.
  • Column manager — reorder, resize, pin (left or right), and hide columns; changes persist on the current view. Substrate: Spec 0028, workspace components. Maturity: Active. Limit: column-pinning behaviour follows AG Grid conventions.
  • Saved views — name a combination of filters, columns, sort, and density; reopen it later on any device tied to your researcher account. Substrate: spa/src/apps/tenant_admin/workspace/SavedViewTab.tsx, spa/src/apps/tenant_admin/workspace/savedViewState.ts, spa/src/apps/tenant_admin/workspace/ViewTabBar.tsx. Maturity: Active. Limit: saved views are personal by default; sharing requires explicit copy-view-link.
  • Density toggle — compact / cozy / comfortable row height; persists per saved view. Substrate: spa/src/apps/tenant_admin/workspace/DensityToggle.tsx. Maturity: Active. Limit: row height follows the shared workspace density contract, not per-table custom row sizing.
  • Details panel — right-side panel showing the full record (including fields outside the table columns), media, related records, history, and inline editor. Substrate: spa/src/apps/tenant_admin/workspace/WorkspaceDetailsView.tsx, recent a11y fix commit cda2f4cd. Maturity: Active. Limit: some fields render a "backend-pending" hint instead of an editor; see Troubleshooting.
  • Batch actions — checkbox selection on multiple rows yields a batch toolbar; available operations depend on your role. Substrate: spa/src/apps/tenant_admin/workspace/BatchActionToolbar.tsx. Maturity: Active. Limit: destructive operations always confirm.
  • Copy view link — copies a URL reproducing the current filters, columns, sort, and density for sharing. Substrate: workspace toolbar. Maturity: Active. Limit: the recipient sees the view subject to their own permissions.

Usability — how you use it​

Your knowledge environment has a sidebar listing the record types you can work with. Click one and you land in its workspace at /app/workspace/<record-type>/. You can bookmark and share the URL. If your project has several record types, each has its own workspace.

The default flow: search, filter, open, edit​

  1. Find a record across the workspace. Click Search database... in the top chrome, or open the command palette and choose Search workspace. Choose Current table when you know the table, or All workspace when you do not. Results open the matching row in the workspace route.
  2. Organize the left sidebar. Star a table, add a group, collapse groups, or reset the sidebar from the sidebar itself or from the command palette. Useful shortcuts: Cmd/Ctrl+K opens commands, Cmd/Ctrl+B toggles the sidebar rail, Cmd/Ctrl+Shift+G creates a group, and Shift+S toggles the current table in Favorites.
  3. Filter the table in front of you. Use the toolbar Filter visible rows box when you only need to narrow rows already loaded in the active table. This quick filter is transient and does not change saved views.
  4. Add filters to narrow. Click Filter, pick a field, choose an operator, choose a value. Filter chips appear in the toolbar under the "filtering by" lead-in. They compose. Remove a chip by clicking its ×; clear all from the toolbar's Clear option.
  5. Tidy the columns. Open the Column manager. Drag headers to reorder, drag column edges to resize, pin a column to the left or right so it stays visible while scrolling, or hide columns by un-checking them.
  6. Save the view. Open the Saved views menu and Save as new. Give it a name like "18th-century figures with manuscript citations". It now lives in your saved views list and appears wherever you sign in.
  7. Open a record's Details. Click the row. The Details panel slides in from the right. It shows the full record, linked media (with citations), related records, and editable fields if your role allows.
  8. Edit inline. Click into a field, change the value, click outside (or press Tab). The change autosaves. A small indicator confirms the save.

Side-by-side reading​

Keep the Details panel open while clicking through rows. As you click each row, the panel updates to show that row's full record; the table stays scrolled and filtered where you left it. Useful for comparing records, auditing a slice, or fact-checking a draft against neighbors. Drag the panel's left edge to resize; the size persists per workspace. Close it with × in the header, or Escape.

Batch operations​

Tick the checkboxes on multiple rows. A batch toolbar appears with operations available for your role — export, tag, archive, delete, depending on what your tenant administrator enabled. Destructive operations confirm before they apply. Deselect by clicking the row's checkbox again, or use Clear selection in the batch toolbar.

Sharing a view with a collaborator​

Click Copy view link in the toolbar. The URL reproduces filters, columns, sort, and density. Paste it into chat or email. Your collaborator opens it and lands on the same arrangement, subject to their own permissions.

What saved views remember (and do not)​

A saved view remembers filters and their values, visible columns and their order/widths/pinning, sort order, and density setting. It does not remember the Quick search term — that stays per-session so you do not accidentally land on yesterday's search. Updating a saved view: open the saved-views menu and choose "Save changes to this view". Creating a new view from the current arrangement: choose "Save as new". Deleting a saved view affects only your copy.

Troubleshooting​

SymptomLikely causeFixWhere to escalate
A toolbar control mentioned here is not visible.The tenant administrator configured the workspace navigation manifest to omit it for this record type.Ask your administrator to expose the control.Tenant admin; reference Spec 0003.
A field shows a small lock or "backend-pending" hint instead of an editor.The field exists in the data model but its editing surface has not shipped yet.Use a non-inline path if one exists (drawer, side panel); otherwise wait — the editor will arrive without your having to relearn anything.See Accessibility on hint focus behaviour.
A column you reordered or pinned reverts after you sign out.The change was made on the default view, not on a saved view.Reopen the column manager, set up the columns, and save as a new view.n/a.
Quick search returns matches but in an unexpected language form.The field is configured for cross-script search across native, transliteration, and translation; matches across all three are surfaced.This is the intended behaviour; see Searching and reading.Tenant admin if the search facet is wrong for the project.
The top search finds a row but the toolbar search does not.They are different tools: top search uses the workspace corpus search, while toolbar search only filters loaded rows in the current table.Open the result from top search, or switch to the right table before using the toolbar filter.n/a.
Inline edit silently does nothing on Tab-out.The field is read-only for your role, or a tenant validation rejected the value.Hover the field — read-only fields display a permissions tooltip; validation errors surface beneath the field.Tenant admin for permissions; see Spec 0025 for the validation contract.
The Details panel will not close.A modal dialog (confirmation, batch operation prompt) is intercepting Escape.Dismiss the dialog first, then press Escape.n/a.
