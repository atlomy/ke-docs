Read the references section on a published entry

When a reader opens one of your published entries, the References section lists the evidence behind it — one row for each place the entry is attested.

What each row shows​

  • One row per occurrence. If a term is attested in twelve passages, the references section has twelve rows. Each row is independent.
  • Your project's citation style. When you have declared citation rules for a collection, each row is rendered in your own scholarly format — author, work, locator (page, chapter, line), and any abbreviations exactly as your field uses them. The format is yours to control, not a fixed platform style.
  • Paired editions. When an occurrence cites both a modern edition and an earlier one, the row bridges them — the primary citation followed by the paired locator, so a reader sees the equivalence at a glance.
  • A quote, when the occurrence carries one, sits with its row.

Where the text comes from​

Each row's text is chosen in order: your declared citation style first; if a collection has no citation rules, a plainer structural composition of the edition's locator fields; and the occurrence's own label as a last resort. A row always renders something — a missing edition never blanks the row.

If the citations read roughly, the citation style for that collection has not been refined yet. Citation styles are tuned per collection (a scholar reviews a proposed style; an administrator applies it); the rows update on the next publish.

Checking before you publish​

Use the draft preview to see the references section exactly as a reader will, before the entry is public — see Preview an entry before publishing.
