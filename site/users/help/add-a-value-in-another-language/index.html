Add a value in another language

When a column is set up to hold several values — one for each language, register, script, edition, or calendar — you fill those values in per record, in the table cell or in the record's form.

Every value here is one you enter. The platform never translates a value into another language or fills one in from another field.

Steps​

  1. Open the record, either by editing the cell in the table or by opening the record's form.
  2. You see one row per value the record already has — each row pairs the value with the language (or register, script, edition, or calendar) it belongs to.
  3. To add a value, click + Add language (the wording follows the column's setup — + Add register, + Add script, and so on). A new row appears.
  4. Choose the language for the new row from the dropdown. It lists the values the column allows; if the one you need is not there, click + new and type it.
  5. Type the value beside it.
  6. Keep the changes: in the table cell, click Save; in the record's form, your edits save on their own. Either way, a row left blank is dropped.

Right-to-left languages​

When a row's language is Arabic, Hebrew, Persian, Urdu, or Aramaic, its value box writes from right to left, so the text reads correctly as you type. Other languages write from left to right.

Choosing the language is a pick, not free typing​

The language for each row is a dropdown of the values the column allows — not a box you type into freely. This keeps every record's values lining up under the same set of languages. When you genuinely need a value the list does not offer, + new lets you add one, and it is tidied into the same standard short form the rest of the column uses. Which languages a column allows is set on the column itself — see Let a column hold several values.

Troubleshooting​

SymptomLikely causeFix
Arabic or Hebrew text writes left to right.The row's language is not set to a right-to-left language.Pick the right-to-left language from the dropdown; the value box switches direction.
The language you need is not in the dropdown.It is not yet in the column's allowed list.Click + new and type it, or ask whoever set up the column to add it (see Let a column hold several values).
A blank row disappeared.Empty rows are dropped when your changes are kept.Fill in both the language and the value.
