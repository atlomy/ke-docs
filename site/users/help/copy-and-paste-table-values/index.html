Copy and paste table values

The workspace table has separate clipboard paths for cells, cell ranges, and full selected rows. Use the one that matches what you want to paste next.

Copy one cell​

  1. Focus the cell whose value you want.
  2. Press Ctrl+C on Windows or Linux, or Cmd+C on Mac.
  3. Move to the cell where the value should go and paste with Ctrl/Cmd+V.

When several rows are selected and the focused column is editable, pasting one copied value fills that same column for each selected row. Read-only fields, derived fields, and fields your role cannot edit are skipped rather than silently changed.

Copy or fill a cell range​

Use a cell range when you want a rectangle of cells, not entire records.

  1. Click the first cell in the rectangle.
  2. Drag to the opposite corner, Shift-click the opposite corner, or hold Shift and use the arrow keys to extend the range.
  3. To target a whole displayed row, use the row-gutter action Select visible cells in row. To target a whole displayed column, open Column actions and choose Select visible column cells.
  4. The status line shows the range shape, such as Cell range: 3 x 3, Row range: 1 x 22, or Column range: 100 x 1.
  5. Press Ctrl/Cmd+C to copy the range as tab-separated values, without row headers.
  6. Paste while the range is active to target that rectangle. A single copied value fills the editable cells in the rectangle. Tabular data follows the visible row and column order; cells that cannot be written are skipped and reported.

Press Escape to clear the cell range. Clearing a cell range does not clear selected rows.

Target individual cells​

Use Target cells when the cells you want are not next to each other.

  1. Select Target cells in the table status line.
  2. Click each cell you want to include. Click a targeted cell again to remove it.
  3. To add a displayed row to the targeted cells, use the row-gutter action Select visible cells in row while Target cells is on. To add a displayed column, open Column actions and choose Select visible column cells while Target cells is on. Using either command again removes that visible group from the targets.
  4. When a data cell has focus, press Enter or Space to add or remove that cell.
  5. The status line shows Sparse cells: N. Targeted cells do not select whole rows, so the row batch toolbar stays separate.
  6. Press Ctrl/Cmd+C to copy only those targeted cells as tab-separated values, in visible row order.
  7. Paste while targeted cells are active to use those cells as the paste target.

A one-cell paste can fill the editable targeted cells. Tabular paste is conservative: the clipboard must contain exactly the same number of values as the targeted cells, or the table rejects the paste and reports the mismatch. Read-only targeted fields are skipped and reported.

Press Escape to clear targeted cells and leave Target cells mode.

Copy full rows​

Use row copy when you want rows as a small table, usually to paste into a spreadsheet.

  1. Focus a row and press Space to select it.
  2. Use Ctrl/Cmd+Space to add or remove another focused row, or Shift with the arrow keys to extend the selection.
  3. Select Copy TSV in the selection toolbar.

The copied text includes the visible columns and a header row with the column labels. It is different from copying cells or a cell range: row copy gives another tool enough structure to paste whole records and columns.

Paste tabular data into existing rows​

If you copied rows from a spreadsheet or from another workspace view, focus the top-left editable target cell and paste. The table lines up pasted columns by header label when the copied data includes headers, otherwise it starts at the focused column. Pasted rows update rows already visible in the table; extra rows are reported as skipped instead of being created by accident.

Paste rows as new records​

On a persisted table where row creation is available, the table can show a Paste rows here target below the displayed rows. Use it when your clipboard contains full tabular rows and you want the workspace to create draft records from them.

The paste creates only fields that can be edited directly in a new draft. Derived fields, linked fields that cannot be set during draft creation, hidden or unknown columns, and values your role cannot write are skipped with a summary. Large pastes ask for confirmation before creating rows.

If New row is unavailable for the current table, paste-as-new-rows is also unavailable. This happens on views that are not backed by one persisted workspace table; use the button's tooltip to see the reason.

Troubleshooting​

SymptomLikely causeFix
Pasting one copied value changed only the last focused cell.No cell range was active, the destination rows were not selected in the table grid, or focus was not in the editable column to fill.Use a cell range for a rectangle of cells, or select the target rows and focus the column to update.
A paste into targeted cells was rejected with a value-count message.The targeted cells were sparse, and the pasted table had more than one value but not exactly the same number of values as the targets.Paste one value to fill all editable targets, or copy exactly one value per targeted cell.
A copied range pasted with some cells skipped.Some target fields were read-only, derived, hidden, unknown, or not editable by your role.Check the paste summary, then edit those fields manually if the table offers an editor.
A browser permission prompt or copy failure appears.The browser blocked clipboard access for this site.Allow clipboard access for your environment and retry.
Some pasted fields were skipped.The pasted columns include read-only, derived, hidden, unknown, or not-yet-editable fields.Check the paste summary, then edit those fields manually if the table offers an editor.
The table did not create new rows from extra pasted lines.Existing-row paste never creates overflow rows automatically.Use Paste rows here on a table where row creation is available.
