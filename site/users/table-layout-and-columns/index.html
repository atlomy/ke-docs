Table layout: sorting, column controls, and the column manager

Purpose​

Every column in your table carries its own set of controls — sorting, a per-column filter, pinning, renaming, row colors — and the table as a whole has a column manager for visibility and order. This page describes each control, where to find it, and what the active view remembers about your arrangement. Read it when you want to know what a control does before you use it; for step-by-step tasks, the help entries linked throughout are shorter.

Features​

  • Each table shows its own columns (Active) — when several of your tables share the same record kind (for example, more than one Terms table), each table shows only the columns that belong to its own source, not the combined set of every same-kind table. So a lemma table shows its lemma columns and an abbreviations table shows its abbreviation columns, even though both are "Terms". Hiding columns for yourself (the column manager, below) is a separate, per-view layer on top of this.
  • Sorting (Active) — sort by clicking a column's name, from the column's header menu, or from the toolbar Sort button. The sort is stored on the active view as you change it.
  • Column header menu (Active) — every column header has a menu with the column's label, type, filter, sort, pinning, visibility, row-color rules, and field actions in one place.
  • Per-column filter (Active) — a filter control in the header menu matched to the column's type: choice columns offer their options, checkbox columns offer checked or unchecked, dates open a date picker, numbers take a number, and text columns match as you type.
  • Column manager (Active) — a dialog listing every column in the table: show or hide, reorder by dragging, search by name or type, and choose the view's display column. In the current workspace build, pinning remains in the column header menu and resizing happens in the table itself by dragging a column's edge.
  • Pinning (Active) — pin a column to the left or right edge from its header menu so it stays visible while you scroll. Pinning is remembered on the active view.
  • Not yet available — Duplicate column and Group by this column appear in the header menu but are grayed out; their tooltips state the reason.

Usability — how you use it​

Sorting​

From a column header​

Click a column's name to sort the table by that column. Clicking the name again reverses the direction, and a third click removes the sort. An arrow in the header shows the current direction. To sort by a second column without dropping the first, hold Shift while clicking the other column's name.

The same controls live in the column's header menu under Sort: Sort ascending, Sort descending, and Clear sort. A sort applied from one column's header menu does not remove a sort already on another column.

From the toolbar​

The toolbar Sort button opens the Sort rows dialog. Pick a field, choose Ascending or Descending, and select Apply. The dialog applies a single field: applying it replaces any sort already active in the table, including sorts on other columns. Clear sort removes the active sort; Cancel or Escape closes the dialog without changes.

What sorting affects​

  • The sort is stored on the active view as you change it, alongside filters and column layout. See Save your table arrangement as a view.
  • While a sort, filter, or search is active, rows follow that order — dragging rows into a hand-arranged order is paused until the table is back in its free order.

The column header menu​

Open the menu with the ⋯ button at the right edge of a column header, or by right-clicking the header. With the header focused, Enter or Space opens it too. The menu is titled with the column's label, and the first editable control is Column label. Column type, filtering, sorting, pinning, wrapping, visibility, and display-column actions are grouped below it. The field key remains visible in record details and the column manager, where it helps administrators identify the underlying field without replacing the label researchers chose.

Filtering from the header menu​

The Filter entry in the header menu shows a control suited to the column's type:

Column typeFilter control
Choice (single or multiple)A list of the column's options, with Any value to clear the choice
CheckboxChecked or Unchecked
Number or yearA number box
DateA date picker
Anything elseA text box that matches as you type

A row stays visible when the column's value matches what you set. Text-like columns match when the displayed value contains your text, ignoring letter case. Date columns use the date picker value as a date: a stored timestamp on the same calendar date still matches the date you picked. If a column is still configured as text even though its values look like timestamps, it keeps text-style matching until someone changes or converts the field type. The condition appears as a chip in the toolbar after "filtering by", with a count of matching rows — the same chips the toolbar Filter button produces, and the two compose. Clear filter in the panel removes this column's condition; the chip's × does the same from the toolbar. See Narrow the current table with filters.

The column manager​

Open it with the toolbar Columns button, or with Manage columns… in any column's header menu. The dialog is titled Manage columns with the table's name, and shows how many columns are visible out of the total.

  • Visible / Hidden / All tabs group the list, each with a count. A search box narrows the list by field name, key, or type.
  • Each row shows the column's label, its field key, a type tag, and four controls: a star (set as display column), an eye (show or hide in this view), and Move up / Move down. Rows can also be dragged into a new order by their drag handle.
  • A checkbox on each row toggles the column's visibility; Show all restores every hidden column at once.
  • Undo, Redo, and Reset step the reordering inside the dialog backward and forward, or return to the order you started from.
  • A preview strip at the bottom shows the first visible columns in the order you are arranging, with the display column highlighted.

Visibility changes apply to the table immediately. Order and display-column changes are held as a draft until you select Save presentation — the saved order applies to the table, the record details fields, and the reader preview sequence.

Two things this dialog deliberately does not do — pinning lives in the column header menu, and column widths are set in the table itself by dragging a column's edge. Both are remembered on the active view.

The display column​

Each view can mark one column as its display column — the column used to identify rows in compact previews. Set it with the star in the column manager or with Set display column in a column's header menu. The column manager's Display column selector offers the same choice plus Use row display label, which returns to the table's own display field — the one whose header carries the Collection display field tag. The choice is saved with the view, and hiding a column does not delete the field.

What the active view remembers​

Sort order, filter conditions, column order, widths, pinning, hidden columns, the display column, row density, and row-color stripe rules are all stored on whichever view is active, as you change them — the toolbar's Undo and Redo step those view changes backward and forward. Views are shared with everyone working in your environment, so arrange a shared view deliberately or duplicate it first. See Save your table arrangement as a view.

Troubleshooting​

SymptomLikely causeFixWhere to escalate
Applying a sort from the Sort button removed the sort I had on another column.The Sort rows dialog applies a single field and replaces the active sort.Re-apply the other column's sort from its header menu, which leaves existing sorts in place.n/a
My column arrangement reverted later.Layout is stored on the active view; you may have been on a different view tab, or a collaborator changed the shared view.Check which view tab is active; duplicate the view for an arrangement collaborators will not change.n/a
I set a display column and the table looks unchanged.The display column identifies rows in compact previews; it does not restyle the table grid.Open a record preview or compact listing to see it in use.n/a
I cannot find pinning in the column manager.Pinning is not in that dialog.Use Pin left or Pin right in the column's header menu.n/a
Duplicate column or Group by this column is grayed out.These controls are visible but not yet available.Hover the control; its tooltip states the reason.n/a
Conditional format says no values are loaded yet.The column has no data in the active table, so there are no values to color by.Add or load rows with values in that column first.n/a
Renaming, editing, or deleting a column fails or is missing.Changing field definitions needs editing access on this table.Ask your environment administrator about your role.Contact your environment administrator.
